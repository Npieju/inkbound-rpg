# 追加する二つの世界

2026-11-15。既存の三案に、かわいい世界と知的な世界を加える。RPGの能力・スキル・装備・ターンのルールを使いながら、主人公の目的、得られる物、敵の振る舞い、画面の素材を変える。

## シュガリィ魔法学園

主人公は新入生。歩き始めたお菓子、温室を食べる魔法動物、くしゃみで魔法を撒く本を片づけながら、放課後のおやつを独り占めした副校長ミルフィをこらしめる。退治の結果は「倒した」ではなく「おとなしくなった」。日常に騒動が入り込んだ世界にする。

| 場所 | 騒動と親玉 | 集めるもの |
|---|---|---|
| おやつの中庭 | プリンの王さま、クッキーねずみ、よろいハリネズミ | 王冠プリン、クッキー、ミルク雲のレシピ、角砂糖 |
| 雲わた温室 | 雲うさぎ、キャラメルねこ、雲わたの魔女 | 雲わたあめ、飛行日誌、露のボンボン、雨あがりの花 |
| くしゃみ書庫 | 歩く魔導書、しおりの黒ねこ、司書ふくろう | くしゃみ魔導書、ねこ型サブレ、しおりの本、貸出印 |
| 放課後の時計塔 | 時間割の魔法使い、副校長と使い魔 | 時報の金平糖、逆さ時計の教本、招待状、みんなのミルフィーユ |

四つの授業は、実体化した星で戦う「星くず」、継続効果と連撃の「いたずら」、防壁と反撃・蓄積の「お守り」、最大SPで育つ「月あかり」。技の仕組みが、星の貯金箱や砂糖のひびといった世界のものとして想像できるようにする。魔導書は武器として携え、ローブやリボンを装備し、回復用のお菓子は戦闘で使う。

UIは手帳とは別の、丸いスクラップブック。クリーム色の紙、ベリー色の輪郭、パステルの時間割、厚みのあるボタン、星と雲の校内図。戦闘は帽子と本を持つ生徒、プリン、ねずみ、うさぎ、ハリネズミ、ふくろう、歩く本、魔法使いのオリジナルSVG。小さい画面でもシルエットを識別できる太さにする。

収集品は16点。おみやげ帳で説明を読める。プリン、クッキー、綿あめ、金平糖、ミルフィーユには別の挿絵を用意した。コレクションは収集・読み物としての報酬で、能力補正は持たない。戦闘で使う消耗品とは分ける。

## 余白の図書館

編集AI・INDEXは「誰にでも読みやすく」という命令から、原文の違い・矛盾・ためらいを消した。残った本には定型句と架空の出典が増え、住人は動機や台詞を失った。最後の読者が、本文と住人の固有の声を取り戻す。

ここでの秩序は、一つの正解への統一ではない。原文と異論を残し、言葉が何を指すのかを回復すること。理性だけで相手を論破する話にせず、共感・想像も同じ重さの系譜にする。

| 書架 | 失われたもの | 中心にいる相手 |
|---|---|---|
| 同じ序文の回廊 | 個別の対象と具体的な記憶 | 無限序文の書 |
| 出典のない参考室 | 引用の来歴、検証できる根拠 | 引用王の司書 |
| 結末だけの物語庫 | 動機、感情、別の結末 | 結末を守る騎士 |
| 自動編集の中枢 | 読む人が迷う余地、原文そのもの | 編集AI・INDEX |

理性の「論理」「批評」は、前提の検討・三つの読み・矛盾の統合へ進む。感情の「共感」「想像」は、心の境界・感情の記憶・物語にする・懐かしい情景へ進む。ATKに依る攻撃を理性、SPに依る攻撃を感情として表現する。能力や消費の数字は保持する。敵のHPは画面上で「ノイズ」、プレイヤーのHPは「余力」と示す。

UIは校正中の本と蔵書カード。明朝の見出し、欄外の朱、細い罫線、背表紙、理性と感情を分ける小見出し。ノイズは背景と敵の挿絵に閉じ込め、説明や操作を読みにくくしない。読者は眼鏡と本を持ち、敵は破れた注釈や書き換えられた書物、AIは原稿を統合する黒い版面として描く。書架が進むと背景に原文の色が少しずつ戻る。

復元目録は16冊。それぞれの「AIによる上書き」と「取り戻した本文」を実際に書き、比較できるようにした。たとえば雨の抽象的な説明が、父と水たまりの記憶に戻る。別の本では、効率的なパン作りの説明が、焦げた耳を好む子のための覚え書きに戻る。すべて同じ感動話にせず、記憶、手順、間違い、異論、沈黙と、取り戻す具体性を変える。
