# 学園の探索UI

V9原案の情報密度を基準に、探索画面を実装し直した。対象は学園スキン。

## 構成

- 色のある章扉と人物カット。情景の背景は使用しない。
- 通常戦3回とボスをつなぐ一画面の経路図。
- 進行に応じた探索、再戦、ボス挑戦、次の章への操作。
- 実際の所持金、育成用XP、既存収集品数。
- 学園・育成・魔法・購買の索引タブ。機能アイコンは単色。

HP/SPは探索画面に表示しない。戦闘画面では既存の体力・魔力表示を使う。味方の使い魔、新たなサイドクエスト、記録手帳などの機能は追加していない。

画面全体を画像として貼る方式ではない。紙面、タブ、見出し、経路、各ノード、人物、操作部が別の要素であり、進行と画面サイズに応じて更新される。人物は既存のゲーム用簡略イラストを使用。

## 実装

`src/school-ui.ts` が表示部品と単色SVG記号、`src/school-ui.css` が学園用の画面構成を持つ。旧マップは他スキンで継続使用。

日本語は Zen Kaku Gothic New の400/700をローカル同梱。ゲームで使う文字をWOFF2サブセットにし、`src/school-font.css` にまとめている。ライセンスは `public/fonts/OFL.txt`。フォントの外部通信はなく、単一HTML版にも埋め込む。追加した文章の文字をフォントへ含める際は `node scripts/subset-school-fonts.mjs` を実行する（この保守作業のみネットワークが必要）。

## 確認

- TypeScriptビルド、既存テスト12件。
- 390×844、320×640で探索画面の表示とタップ領域を確認。
- スキル画面への切替、探索から敵情報を開く導線を確認。

原案の実装化であり、全キャラクター・敵・ボスの再作画や全スキンの改訂はこの変更に含まない。
