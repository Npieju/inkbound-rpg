# 現行仕様

4系統・28スキル。複数の系統から習得できる。技と派生技を4枠にセットし、常時効果は習得すると自動で有効になる。初期XPは40。

## 能力と計算

HP＝70＋14×強化回数、SP＝20＋6×強化回数＋装備補正、ATK＝11＋3×強化回数＋武器補正、DEF＝2＋2×強化回数＋防具補正、AGI＝10＋3×強化回数＋装備補正。各能力の強化費用は8＋5×その能力の強化回数XP。

魔法威力＝最大SPの70%＋4。会心率は5%＋(AGI−10)×0.8%、最大45%。物理攻撃で差し引く防御の係数は0.5、魔法攻撃は0.25。会心倍率は1.65。

毒・裂傷・燃焼のダメージは敵の行動前に発生し、敵を倒せばその行動はなくなる。追撃・反撃から追加の追撃・反撃は発生しない。防壁の上限は最大HPの60%＋DEFの2倍。蓄勢の上限はDEFの6倍。

## 状態異常と装備

消費SP増加の効果は2ターン続き、スキルの消費SPを2増やす。平静の衣は増加量を1にする。血の契りはSPの代わりにHPを消費する。耐毒のベストは毒のダメージを半減する。城主は仲間が倒れると1行動使って吸収し、攻撃力を上げる。

ゲームの数値は調整中。
