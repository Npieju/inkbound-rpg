# 現行仕様：ジョブを参考にした混成ツリー

初期数値で実装した開発版。初期40XP。能動技・変化技は4枠、常時効果は習得で有効。系統間の排他制限なし。旧ツリーと旧セーブの移行は撤去。

HP=70+14×投資、SP=20+6×投資＋装備、ATK=11+3×投資＋武器、DEF=2+2×投資＋防具、AGI=10+3×投資＋装備。各能力の費用は8+5×購入回数XP。術威力=最大SP70%+4。会心率は5%+(AGI−10)×0.8%、最大45%。

物理ダメージの防御係数0.5、術は0.25、会心倍率1.65。継続ダメージは敵の行動前に発生し、対象が死ねばその行動はなくなる。誘発した追撃・反撃はさらに追撃・反撃を生まない。防壁上限は最大HP60%+DEF2倍、蓄積上限はDEF6倍。

## 敵と資源

術乱は2行動の間、通常の技に追加SP2。平静の衣は追加分を1へ減らす。血の契りはHP支払い。解毒のベストは毒ダメージを半減。敵の説明には特定の装備を買う指示を含めない。王は仲間の死を吸収して1行動を使い強化する。

セーブv4のみ。戦闘途中の敵パラメータを再読込で信用せず、マップから再開。数値は初期値。網羅的な自動攻略・勝率比較はこの改訂では行わない。
