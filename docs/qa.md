# 起動・効果の確認

旧ツリー用の攻略シミュレーションを削除。現行は、能動と常時の編成、基礎値条件、複数命中と傷、回収、反撃・蓄積、SP依存の術、HP支払い、見切り、術乱、保存形式を短い動作確認で扱う。型チェックとブラウザでの習得・編成・戦闘操作を確認する。ゲームの面白さを形式的な完走率で保証するものではない。

ブラウザで、盗賊の能動技と傷刻みの習得、常時効果が4枠を使わない編成、三連斬の複数命中から裂傷が発生する戦闘、処刑剣のATK条件と現在値表示を確認。320×568と844×390で戦闘コマンドが画面内、375×667でツリーの内容領域だけがスクロールすることを確認。戦闘中の「常時」から効果全文を見返せる。
