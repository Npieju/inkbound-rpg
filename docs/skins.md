# 世界観と画面表現

スキン変更前の保存点は `v0.3.0-pre-skins`（8f5b147）。

ゲームの同じルールを、異なる世界の出来事として表現する。スキンは色の設定ではなく、タイトル・舞台・役割・固有名詞・語り・絵・画面の形を持つ。威力、コスト、条件、効果時間は全案で一致する。

| | 遠征手帳 | NEON DEPTHS | 武芸帳 |
|---|---|---|---|
| 主人公 | 辺境の街道を調べる冒険者 | 閉鎖都市に潜る回収屋 | 四つの道場に挑む武芸者 |
| 目的 | 四地域の主を倒し、街道の調査を終える | 四区画の管理機を停止する | 四道場の師範に勝つ |
| 成長 | 経験を訓練と職業の技に変える | 戦闘データを機体とモジュールに使う | 稽古で鍛え、流派をまたいで技を学ぶ |
| 通貨と経験 | 金貨／経験 | クレジット／データ | 文／修練 |
| 構図 | 折り目のある地図、野営の付箋、記入欄 | 区画配線図、機体HUD、モジュール回路 | 横罫の帳面、朱印、門札、伝承の系譜 |
| 質感 | 生成りの紙、濃い茶の線、オリーブの布 | 濃紺、蛍光シアンと橙、角形のパネル | 和紙、墨、朱、藍、明朝の見出し |
| 戦闘 | 木版画風の旅人と魔物 | ワイヤーフレームの機体と管理機 | 筆線の剣士と人形、稽古場 |
| 回復の表現 | 戦いのあとは野営で手当て | 戦闘終了後に修復・再充電 | 一戦ごとに手当てして次の試合へ |
| 語り | 手帳に短く書き留める | 機体の交戦記録 | 試合と技の記録 |

「世界観」から随時変更できる。戦闘中も変更可能で、ターンや資源を消費しない。選択はゲームの進行とは別に保存する。既存ログはルール側の標準文を保持し、表示時に選択した世界の語彙と語りへ変換する。技・道具・敵の名前は単一の辞書から画面、説明、ログ、読み上げに一貫して適用する。

数字と条件の説明は、雰囲気のために隠さない。世界の紹介文は目的や場所の事情を書く。プレイヤーの感情を代弁する標語は置かない。
