## 確認した原作の枠組み

[初代の保存されたアプリ説明](https://stickman-rpg.appstor.io/)と[初代のプレイ記事](https://dotapps.jp/static/articles/qqfs7fmfjbn4pnqf): XPで5能力とスキルを伸ばし、4枠にスキルをセットする。技はSPと待機時間を使う。通常攻撃・スキル・アイテム・逃走。複数の敵を倒して勝利し、クリア済み戦闘へ再挑戦できる。

HP/SPの戦闘終了時の全回復はユーザーが補足した要件として維持する。1人パーティ・移動なし・スマートフォン向け画面も維持する。

## 今回の実装仕様

以下の倍率、期間、価格、敵の数値、習得XPは今回の小規模なゲーム向けの調整値。原作の数値と偽らない。

- 通常攻撃・4枠スキル・アイテム・逃走を基本コマンドにする。固定周期の大技と汎用75%軽減の防御を廃止。
- 敵1〜2体の編隊を扱い、対象を選択できる。敵を1体倒せばその敵の以後の行動がなくなる。全体攻撃には大きなSP費用を置く。
- 敵にもATK・DEF・AGIを設ける。AGIは命中・回避に使い、会心率や追加手番には流用しない。
- 攻撃強化・防御強化・速度強化・敵の防御低下・速度低下を期間付きで実装する。同種強化の無限乗算はさせず、強さと残り期間を管理する。
- チャージは次の攻撃行動だけを増幅。攻撃強化・防御低下との組み合わせを可能にする。
- SP効率のよい単体攻撃、準備を要する決定打、高消費の全体攻撃を分ける。
- 毒とスキル封印を導入。封印中も通常攻撃・アイテム・逃走は選択可能。敵の特徴と耐性を事前に確認できるようにする。
- HP回復・全回復と状態治療・HP/SP回復アイテム・状態治療アイテムを扱う。
- 武器・防具を所持して持ち替えられるようにし、DEF、AGI、SP、毒耐性、封印耐性を選択軸にする。
- 全技を高倍率化するのではなく、攻撃／強化／回復妨害の効果を持つ12技に置き換える。スキルツリーは今回の必須要件として残し、複数の枝を全取得しないと進めない条件を撤廃する。
- 既存のセーブはステージ・お金・装備を維持し、変更する旧スキル分をXPへ払い戻す。能力・スキルは無料で振り直し可能にする。

## 検証

同じXP・装備予算で、攻撃強化とチャージを組む攻略、重複した低SP攻撃と回復による攻略、通常攻撃中心の攻略を比較する。敵編隊、DEF、AGI、回復役、状態異常と耐性のそれぞれが結果へ影響するかを記録する。

クリアできるテストとは別に、勝敗、ターン数、SP消費、必要な編成、対策を外した場合との差を出す。結果を見て今回の数値を調整する。原作と同等の面白さの確認には、引き続きプレイによる比較が必要であり、自動テストだけで達成済みとはしない。
