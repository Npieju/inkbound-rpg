# School Gothic

Zen Kaku Gothic New, weights 400 and 700. SIL Open Font License; see OFL.txt. Static subsets delivered by Google Fonts containing the characters used in this game, embedded in src/school-font.css. Served locally, including in the offline edition. New UI text outside the subset uses the system Japanese fallback.
