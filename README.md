# INKBOUND

[ブラウザで遊ぶ（PC・スマートフォン）](https://npieju.github.io/inkbound-rpg/)

移動なしの固定マップで戦い、XPを能力とスキルに投資するソロRPG。TypeScript製、実行時の外部依存なし。

## 育成

初期40XPからHP / SP / ATK / DEF / AGIを伸ばし、4系統・28ノードを自由に混成できます。職業の固定選択はありません。

| 系統 | 育成のつながり |
|---|---|
| 戦士 | 強斬から防御崩し・範囲へ変化。技の後の通常攻撃を強化し、撃破でSPを回収 |
| 盗賊 | 三連斬の各命中で傷を重ねる。回避→必中会心→追撃。継続ダメージから吸収 |
| 守護者 | DEFで防壁・反撃・蓄積が育つ。防いだ力を通常攻撃か解放撃で使う |
| 魔術師 | 最大SPで術と回復が育つ。燃焼、防壁、高消費の圧縮、HPを払う血の契りへ分岐 |

能動技と変化技は戦闘の4枠へセット。同じ技も複数セットでき、待機は枠ごと。常時効果は習得だけで有効になり、枠を使いません。処刑剣・解放撃・魔力圧縮・血の契りの4ノードだけに、装備を除く基礎ステータスの条件があります。

ノード一覧と初期数値は [現行仕様](docs/design.md)。自由な振り直しで能力・習得費用をXPへ戻せます。

## 進行・戦闘

通常戦3地点を突破するとボス解放、撃破で次のマップへ。全4ステージ。再戦でXPとGを稼げます。敵1〜2体から攻撃対象を選びます。戦闘終了でHP/SPは全回復。

コマンドは通常攻撃・スキル・アイテム・逃走。キーボードは攻撃A、逃走R、ポーションH、技1〜4。毒・裂傷・燃焼、防壁・反撃・蓄積が戦闘に働きます。術乱は技の追加SP費用で、技を禁止する状態ではありません。装備は購入後も着替え可能。耐性装備は被害や費用を軽減します。

## 起動

Node.js 22.18以上。

```sh
npm install
npm run dev
npm run build
npm run preview
```

`dist/`を静的ホストへ配置できます。`dist/inkbound.html`は単一ファイル版。ルールは`src/game.ts`、表示は`src/main.ts`に分離しています。

## セーブと公開

開発版セーブv4をこのブラウザのlocalStorageへ保存します。以前の試作のセーブは引き継ぎません。戦闘中の再読込は全回復してマップに戻ります。

mainへのpushでGitHub Actionsが起動確認とビルドを行い、GitHub Pagesへ公開します。スマホはsafe-areaと100dvhに対応し、マップ・戦闘はページスクロールなし、育成・商品は内容領域のみスクロールします。

研究の参照元は [調査と実装](docs/reference-implementation.md)。現在の数値は初期調整値です。自動攻略の勝率を面白さの保証として扱いません。
