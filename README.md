# INKBOUND

**小さな冒険、大きな一撃。** 棒人間が戦う、1画面完結のコンパクトなRPG。

**[ブラウザで遊ぶ（PC・スマートフォン）](https://npieju.github.io/inkbound-rpg/)**

TypeScript製。ゲーム本体の実行時依存はありません。フレームワーク、バックエンド、外部画像、アカウント登録も不要です。Goro SatoのStickman RPGのIの固定マップ・1人パーティを軸に、II・IIIのXP投資とスキル編成も参考にしたオリジナル作品です。

原作の具体的な攻略例と実装の対応を [調査と仕様](docs/reference-implementation.md)、再現可能な比較を [戦闘比較](docs/balance-results.md) に記録しています。倍率・習得条件・敵編隊は今回の調整値です。

## 起動

Node.js **22.18以上** と npm（または pnpm）が必要です。

```sh
npm install
npm run dev
```

ターミナルに表示されたローカルURLを開いてください。

```sh
npm test       # 戦闘・成長・購入・セーブ・全ステージ進行のテスト
npm run build # TypeScriptの型チェック + 静的ビルド
npm run preview
```

`dist/` を任意の静的HTTPホストへ配置できます。相対パスでビルドするため、サブディレクトリにも置けます。**`dist/inkbound.html` は単一ファイル版**で、ダウンロードしてブラウザで直接開けます。通常の `dist/index.html` はHTTPホストで開いてください。フォントは端末のシステムフォントを使い、外部フォントへの接続はありません。単一ファイル版を `file://` で開いた際の保存可否はブラウザ設定に依存します。

## 遊び方

- 初期 **30 XP** を **HP / SP / ATK / DEF / AGI** の強化、またはスキル習得に使います。強化するごとに必要XPは上がります。
- 固定マップの通常戦3地点を順に突破するとボス解放。クリア済み地点への再戦で資源を稼げます。
- **攻撃・強化・回復妨害の3系統、計12技のスキルツリー**。前提スキルと必要XPを満たして習得します。
- 習得した技から **4枠** を編成。同じ技も複数セットでき、クールダウンは枠ごとに管理されます。
- **攻撃 / 逃走 / HP回復** はキーボード **A / R / H**、セットした技は **1〜4**。技はSPと枠ごとの待機時間を使います。
- 敵1〜2体から攻撃対象を選べます。回復役の撃破順、強化→チャージ→決定打、低消費技の重複セット、全体攻撃、命中回避、耐性装備を相手に応じて組み合わせます。
- HP/SP回復薬と毒・封印の治療薬があり、回復や補助も1ターンを使います。能力とスキルはXP全額返却で振り直せます。
- 勝利でお金とXP。XPは自動消費されず、能力強化とスキル習得に自由に振り分けます。RANKは累計獲得XPに応じた目安表示です。
- **各戦闘が終わるとHP・SPは自動で全回復。** 休憩操作は不要です。回復スキル・ポーションは戦闘中に使います。攻防・AGI・SP・状態異常耐性を持つ装備を購入し、購入済み品は持ち替え可能。
- 全4ステージを攻略するとエンディング。敗北してもお金・経験値は失いません。

## セーブ

各操作後にブラウザの `localStorage` に自動保存します。別端末・別ブラウザ・別オリジンには引き継がれません。保存が禁止されていてもゲームは動きますが、再読込で進行が消えます。戦闘中の再読込はHP/SP全回復でマップに戻ります。旧v2セーブは進行・装備を移行し、旧スキル費用を返却します。遊び方から確認画面を経て初期化できます。

## 公開・更新

GitHub Pagesで公開しています。`main`へのpush後、`.github/workflows/pages.yml` がテスト・型チェック・ビルドを実行し、成功した `dist/` を自動デプロイします。リポジトリの Settings → Pages → Source は **GitHub Actions** です。

スマートフォンでは公開URLをSafariやChromeで開いてください。縦画面を基準に、HP・SP・所持金・XPを常時表示し、下部のマップ・能力・スキル・道具屋で画面を切り替えます。マップと戦闘画面はページスクロールなし、育成と買い物は内容領域だけがスクロールします。主要文字は14〜18px、補足は12px以上、主要タップ領域は44px以上です。進行状況はその端末・ブラウザ内に保存されます。

## 構成

```text
src/game.ts   純粋なTypeScriptのゲームルール（DOM・保存・時刻への依存なし）
src/save.ts   バージョン付きセーブの検証と保存
src/main.ts   ブラウザUI、入力、演出
src/art.ts    オリジナルのSVGキャラクターと背景
src/style.css レスポンシブな画面
tests/        Node.js標準テストランナーによる検証
```

ゲームルールと描画を分離しているため、`game.ts` を別UI、Canvas、デスクトップラッパーなどへ持ち運べます。ステージは `STAGES`、装備は `ITEMS` で定義しています。
