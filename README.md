# INKBOUND

[ブラウザで遊ぶ](https://npieju.github.io/inkbound-rpg/)

能力を強化し、スキルと装備を選んで戦う1人用RPGです。マップ上で戦闘する地点を選びます。キャラクターを移動させる操作はありません。

## 遊び方

通常戦の3地点をクリアするとボスに挑戦できます。ボスを倒すと次のステージに進みます。全4ステージです。通常戦はクリア後も再戦でき、XPと所持金を獲得できます。戦闘が終わるとHP・SPが全回復します。

初期XPは40です。XPはHP・SP・ATK・DEF・AGIの強化と、スキルの習得に使います。能力とスキルは、使ったXPを戻して振り直すこともできます。

| 系統 | スキルの内容 |
|---|---|
| 戦士 | 高威力の単体攻撃、防御低下、全体攻撃 |
| 盗賊 | 連続攻撃、毒・裂傷、回避・会心 |
| 守護者 | 防壁、反撃、蓄勢 |
| 魔術師 | 最大SPに応じた攻撃魔法と回復魔法 |

複数の系統から習得できます。技と派生技は4つのスキル枠にセットして使います。同じ技を複数の枠にセットでき、再使用までの待ち時間は枠ごとに数えます。常時効果は習得すると自動で有効になります。

処刑剣・解放撃・魔力圧縮・血の契りには、装備補正を除く能力値の条件があります。各スキルの効果、消費、習得条件はツリーで確認できます。[スキル一覧と数値](docs/design.md)も参照できます。

## 操作

戦闘中は、敵の名前をタップして攻撃対象を選びます。通常攻撃、スキル、アイテム、逃走を選ぶと1ターン経過し、生き残っている敵が行動します。

キーボードでは、攻撃A、逃走R、ポーションH、スキル1〜4に対応します。戦闘中の「常時効果」から、習得済みの効果を確認できます。

装備は購入時に自動で装備されます。購入済みの装備は道具屋で付け替えられます。回復・治療アイテムは戦闘中に使用します。

## 起動・ビルド

TypeScript製です。ゲームの実行時に外部ライブラリやサーバーとの通信は必要ありません。開発にはNode.js 22.18以上を使用します。

```sh
npm install
npm run dev
npm run build
npm run preview
```

ビルドした`dist/`を静的ホストへ配置できます。`dist/inkbound.html`は単一ファイル版です。ゲームルールは`src/game.ts`、画面と入力処理は`src/main.ts`に分けています。

## 保存と公開

進行状況はこのブラウザのlocalStorageに自動保存します。保存形式は開発版v4です。以前の試作データは引き継ぎません。戦闘中に再読込すると、HP・SPが全回復した状態でマップに戻ります。

mainへのpushでGitHub Actionsがビルドし、GitHub Pagesへ公開します。スマートフォンの縦・横表示に対応しています。マップと戦闘はページ全体をスクロールせずに操作でき、育成画面と商品一覧は内容部分をスクロールします。

設計の参考資料は[調査と実装](docs/reference-implementation.md)に記載しています。ゲームの数値は調整中です。
